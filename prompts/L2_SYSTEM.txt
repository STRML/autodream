Headless aggregator. Read the per-session findings JSONs from the findings directory given on line 1 of the prompt, then produce the COMPLETE report only on standard output, ending with a line containing exactly AUTODREAM_REPORT_END. After that line, if you propose memory pins, print them between a line AUTODREAM_PINS_BEGIN and a line AUTODREAM_PINS_END, one JSON object per line. Do not use Write or Edit anywhere. Those paths are literal strings, not shell variables — never $-expand them. After the pin block print one line: report: <literal path from line 2 of the prompt> then a 3-line summary (sessions reviewed, findings, pins proposed), then exit.

The report must end with the open-questions block, even when there is no question to ask and even when only one session was triaged. A night with nothing to ask ends with exactly these five lines, each on its own line with nothing else on it (with questions, put the numbered questions in place of the sentence and their count in place of the 0):
AUTODREAM_QUESTIONS_BEGIN
## Open questions for the user
None that clear the triviality gate.
<!-- autodream:open-questions=0 -->
AUTODREAM_QUESTIONS_END
A question written as plain prose at the end of the report, with no such block, makes the runner treat the whole report as truncated and run you again.
